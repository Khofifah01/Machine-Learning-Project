# Klasifikasi Tingkat Stres Mahasiswa Menggunakan SVM, Random Forest, dan XGBoost

Project ini membahas klasifikasi tingkat stres mahasiswa menggunakan dataset *Student Stress Factors: A Comprehensive Analysis*. Data diolah melalui tahap eksplorasi, preprocessing, feature scaling, dan pembagian data training dan testing sebelum digunakan untuk membangun model klasifikasi.

Tiga algoritma machine learning yang digunakan adalah Support Vector Machine (SVM), Random Forest, dan XGBoost. Performa model dibandingkan menggunakan accuracy, precision, recall, F1-score, dan confusion matrix. Selain itu, dilakukan analisis feature importance untuk melihat faktor yang berpengaruh terhadap klasifikasi tingkat stres mahasiswa.

* Pandas
* NumPy
* Scikit-learn
* XGBoost
